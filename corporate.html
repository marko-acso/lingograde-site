Pre-Employment Language Testing

Pre-made test library, standardized candidate tests, and full candidate management - built for HR.

LingoGrade is a pre-employment language testing platform. HR teams use it to screen job applicants, verify candidate language level before a hiring decision, and run structured tests and assessments across a candidate pipeline.

Pre-made Test Library

A ready-to-assign catalog of pre-made pre-employment tests across 12 languages and 6 CEFR levels (A1 to C2) - 72 standardized tests total. Every test is calibrated to the same rubric, so every candidate in the pipeline is measured the same way.

Example pre-made tests: German A2 Pre-Hire, English B2 Pre-Hire, French C1 Pre-Hire, Spanish B1 Pre-Hire, Italian A2 Pre-Hire, Bulgarian B2 Pre-Hire - same test, same result format, every time.

Tests & Assessments

Every test is a structured 25-minute language assessment with standardized speaking and writing prompts. Auto-scored CEFR results (A1 to C2). A standardized 7-page PDF test report delivered within one hour of completion.

What every test includes: active and passive CEFR level, 5 structural-pattern findings, skill-by-skill breakdown (grammar, vocabulary, fluency, coherence, task fulfilment), and a clear summary HR can use to support the hiring decision.

Candidate Management

An HR candidate-management workflow: add candidates, send test invitations, track candidate pipeline status (Invited → In Progress → Scored → Decision), and download CEFR reports per candidate. One consolidated view of every job applicant you are screening.

For HR: candidate list per role, real-time status, bulk invite, single invoice, report export (PDF), and a Team Summary across the candidate pool so you can compare applicants side by side.
